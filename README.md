# 🚀 AI, Data Science & Full-Stack Developer Portfolio

A modern, high-performance, and visually striking portfolio website designed specifically for professionals working across **Artificial Intelligence**, **Data Science & Machine Learning**, and **Full-Stack Web Development**.

Built with pure, vanilla **HTML5**, **CSS3 (Modern Glassmorphism & Cyberpunk-infused Dark Theme)**, and **JavaScript (ES6+)** with zero heavy framework overhead.

---

## ✨ Key Features

### 🧠 1. Interactive Neural Network Canvas
- Fullscreen background rendering interactive neural nodes and synaptic connections.
- Dynamic mouse collision/avoidance and proximity-based line rendering running at 60 FPS.

### 🧪 2. In-Browser AI & Data Science Lab
Interactive real-time client-side experiments demonstrating domain expertise directly in the browser:
- **NLP Sentiment Analysis Engine**: Real-time lexical analysis, emotional valence calculation, polarity meter, and key token extraction.
- **Ordinary Least Squares (OLS) Linear Regression Canvas**: Interactive Cartesian plane where users click to place data points, dynamically calculating the line of best fit ($y = mx + b$), slope, intercept, and $R^2$ accuracy score.
- **Neural Forward Pass Visualizer**: Multilayer perceptron (MLP) simulator with real-time sliders for inputs, synaptic weights, bias, ReLU activation, and Sigmoid ($\sigma$) output probabilities.

### 💻 3. Modern Cyberpunk Terminal & Dynamic Metrics
- Interactive code terminal simulating live model compilation, CUDA inference benchmarking, and real-time streaming metrics.
- Animated numerical counters calculating accuracy percentage, completed projects, and years of experience.
- Automated typewriter effect cycling through technical focus areas.

### 🛠️ 4. Categorized & Filterable Showcases
- **Skills Matrix**: Filter skills on-the-fly across AI & Deep Learning, Data Science, Web Development, and DevOps/Cloud.
- **Featured Projects Grid**: Filterable project showcases complete with tech stack tags, architecture descriptions, source code, and live demo links.

### 📱 5. Responsive Design & Modern UI/UX
- Responsive across mobile, tablet, laptop, and ultra-wide screens.
- Dark glassmorphism panels, CSS gradient accents, micro-animations, and smooth scroll navigation.

## 🚀 Quick Start

No installation, build tools, or server setup required!

### Option 1: Open Directly in Browser
Double-click `index.html` or open it with your browser of choice (Chrome, Edge, Firefox, Safari).

### Option 2: Run with a Local Static Server

Using Python:
```bash
# Python 3
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.

Using Node.js / npx:
```bash
npx serve .
```
